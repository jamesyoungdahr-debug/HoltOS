DISPLAY PAGE / HDR / VRR (Liam's question, 2026-09-12)
-----------------------------------------------------
System Settings > Display was missing outright: kscreen (the KCM) was not
in packages.x86_64. Fixed in build 10. Beyond that, Plasma 6 shows
resolution/refresh/scale always, and HDR / VRR / wide gamut only when the
DRM driver reports the capability: hyperv_drm reports none (VM), AMD/Intel
get them from the Mesa/amdgpu/i915 stack already in the image, NVIDIA
needs the driver installed by hardware detection (PLAN step 7, real
machine only) plus KWIN_DRM_ALLOW_NVIDIA_COLORSPACE=1 for the HDR toggle
on Plasma >= 6.2 (KDE hid it on NVIDIA behind that env var because of a
login-blocking driver bug; not shipped by default — enable per machine).
GPU-PV / dxgkrnl in Hyper-V cannot test any of this: it gives /dev/dxg
(compute) with no DRM device, no NVIDIA PCI device, no nvidia.ko.

HOW TO DRIVE THE TEST VM (Hyper-V "holtos-test")
-------------------------------------------------
Tooling lives in the session scratchpad (C:\Users\Liam\AppData\Local\Temp\
claude\C--projects-holtos\<session>\scratchpad\): vm.ps1 (non-elevated
wrapper) runs vmctl.ps1 elevated. Actions: state | iso=<path>|none |
start | off | shutdown | bootdisk | bootdvd | net=on|off | shot=<png> |
type=<text> | key=<vk> | keydown/keyup=<vk> | holdkey=<vk>,<secs> |
click/dblclick/rclick/move=<x>,<y> | sleep=<s>. Screenshots come from
Msvm_VirtualSystemManagementService.GetVirtualSystemThumbnailImage at the
guest's real resolution (1024x768); keyboard via Msvm_Keyboard TypeKey
per character (VkKeyScan + Shift); mouse via Msvm_SyntheticMouse
SetAbsolutePosition + SetButtonState (Click() alone does nothing).
Synthetic clicks do NOT activate taskbar/desktop icons: open apps with
KRunner (keydown=18 key=113 keyup=18, type name, key=13). Then SSH
(key: scratchpad/vmkey): in Konsole type
  sudo systemctl start sshd && mkdir -p ~/.ssh && echo '<pub>' > ~/.ssh/authorized_keys
The VM's address changes when the host's Default Switch renews its subnet
(172.30.x -> 172.29.x after the 2026-09-12 host reboot); read it off a
Konsole screenshot (`ip -4 -br a`) — Get-VMNetworkAdapter shows nothing
(no KVP daemon) and the host neighbour cache also lists WSL.
Live session user liveuser (passwordless sudo). Installed test user
holtos / password holtos — sudo over ssh needs `echo holtos | sudo -S`,
and three wrong attempts trip pam_faillock for 10 minutes.
Installer at 1024x768: Next (977,145) on early pages, (977,61) once the
window grows on Summary; Erase disk radio (20,254); Users fields: name
(110,233), password (110,434), repeat (316,434), same-password box
(19,494). Erase-disk install of build 9 took under 3 minutes.
guest-checks.sh (scratchpad) is the in-guest verification script; run it
with `ssh ... 'bash -s' < guest-checks.sh`.
The DVD stays attached: boot order decides (bootdisk / bootdvd).
A screenshot that looks frozen (stale panel clock, a closed window still
drawn) is usually KWin on llvmpipe sitting on its last frame until input
arrives: send move=x,y and shoot again before calling it a hang (seen
2026-09-13; KWin was answering D-Bus the whole time).
